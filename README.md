# Файловый менеджер на PHP

Учебная практическая работа: загрузка, просмотр, скачивание и удаление файлов.

## Запуск
1. Установите PHP 8.x и добавьте папку PHP в `PATH`.
2. Убедитесь, что PHP может записывать в папку `uploads`.
3. Откройте CMD в папке проекта и выполните `php -S localhost:8000`.
4. Откройте http://localhost:8000. Настройки PHP доступны на `/info.php`.

## Возможности
- Загрузка файла с проверкой ошибок, расширения и размера (до 5 МБ).
- Разрешённые расширения: jpg, jpeg, png, gif, pdf, txt, docx, xlsx, zip.
- Безопасное имя и защита от перезаписи файлов.
- Список файлов, размер, дата, общее количество и объём.
- Скачивание, подтверждение удаления и просмотр параметров PHP.

Ответы на контрольные вопросы находятся в `QUESTIONS.md`. Пример настроек — в `php.ini.example`.
